# Songyun Outline

宋韵清和的配套 Obsidian 插件，为阅读视图和编辑视图提供独立实现的页边纸签目录。

## 功能

- 直接读取当前笔记标题，不依赖第三方目录插件。
- 纸签按 H1–H6 分层，全部左对齐，同一章节下的子标题收紧分组。
- 静止时只显示无字纸签，当前章节以绛红细边轻微突出。
- 悬停纸签时原位展开标题；点击纸签跳转到对应章节。
- 阅读滚动和编辑位置会自动更新当前纸签。
- 目录显示或隐藏都不会改变正文位置，正文继续使用主题的居中布局。

## 安装

1. 解压 `Songyun-Outline-v1.0.1.zip`。
2. 将解压出的 `songyun-outline/` 文件夹放入 `<你的 Vault>/.obsidian/plugins/`。
3. 在 Obsidian 的「设置 → 第三方插件」中启用 **Songyun Outline**。
4. 在插件设置中分别控制阅读视图、编辑视图和移动端的显示。

主题需启用 **Songyun Qinghe / 宋韵·清和**。插件会优先使用主题中的 `--song-*` 变量，也提供独立的后备色。

## 命令

- **切换页边纸签目录**：临时开启或关闭目录。
