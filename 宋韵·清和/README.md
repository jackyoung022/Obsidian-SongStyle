# 宋韵·清和

一套以宋式审美为基调的 Obsidian 主题：暖纸、墨色、绛红与灰绿，强调留白、细线与安静的信息层级。

## 色板

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 绛红 | `#8C2F2D` | 主强调、标题、当前文件 |
| 胭脂 | `#B76F6A` | 悬停、列表标记、次强调 |
| 暖灰 | `#8E8075` | 次级文字、图标、分隔 |
| 灰绿 | `#B7C5B7` | 引用、标签、区块背景 |
| 宣纸 | `#EDE6D9` | 侧栏、画布、基础纸色 |

正文区域使用更浅的纸面 `#F8F3E9`；深色模式采用黛蓝纸面与温润的米白字色。

## 深色 · 灯下观书

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 黛蓝 | `#4F6072` | 边框与层次，向深处延伸纸面色阶 |
| 陶红 | `#B56A58` | 按钮与交互点缀 |
| 暖金 | `#D9B07C` | 一级标题、粗体、行内代码 |
| 青玉 | `#8DB8A7` | 链接、标签、三级标题 |
| 米白 | `#F1EADF` | 正文与笔记标题 |

正文底色为 `#2B3744`，侧栏为 `#26313D`，Ribbon 为 `#212C37`。细颗粒与浅色版使用相同的 128px 图案、噪声频率和种子；深色颗粒使用中性灰增强明暗对比，并以 `soft-light` 柔光混合，SVG 透明度为 `0.30`，铺在内容下方。陶红小字号文字使用较亮的衍生色 `#E0A18D`。

在「设置 → 外观 → 基础颜色」中选择「深色」即可启用。

## 使用

1. 在 Obsidian 的「外观」中选择主题「宋韵·清和」。
2. 主题同时适配浅色与深色模式。
3. 安装 Style Settings 后，可在主题设置中调整「正文栏宽度」。
4. v1.2.1 已内置宋韵图标，无需额外 CSS 片段。安装 Style Settings 后，开启「使用 Obsidian 原生图标」可恢复原生外观。升级后可关闭旧版独立图标片段。

官方主题库名称为 **Songyun Qinghe**。手动安装保留「宋韵·清和」名称，外观一致。

## 推荐字体

先将字体安装到操作系统，再进入「设置 → 外观 → 字体」选择。字体不包含在主题包中。

| 位置 | 推荐字体 | 设置名称 |
| --- | --- | --- |
| 正文 | [霞鹜文楷](https://github.com/lxgw/LxgwWenKai) | `LXGW WenKai` |
| 界面 | [阿里巴巴普惠体 2.0](https://www.alibabafonts.com/) | `Alibaba PuHuiTi 2.0` |
| 等宽 | [JetBrains Mono](https://www.jetbrains.com/lp/mono/) | `JetBrains Mono` |
| 标题 | macOS 宋体 / [思源宋体](https://github.com/adobe-fonts/source-han-serif) | 由主题自动使用 `Songti SC` / `Source Han Serif SC` |

截图使用 16px 正文和 780px 主题默认行宽。未安装上述字体时，会使用系统回退字体。安装后如字体尚未显示，请重新打开 Obsidian。

## 设计取意

- 不做具象的古风装饰，以宋画的留白、册页的细边和器物的低饱和色感为线索。
- 深浅色编辑区与侧栏使用同一套 128px 平铺细颗粒，参考中国色网站的均匀细噪点。
- 浅色 H1 使用朱砂，深色 H1 使用暖金；H2 用灰绿或青玉细竖线建立秩序。
- 引用与提示块使用展开书卷：左右双轴、细边纸面、主题颗粒。浅色为暖宣，深色为黛笺。
- 提示块保留类型图标与颜色，标题以卷首题签呈现；折叠、链接和编辑操作沿用 Obsidian 原有方式。
- 标签用灰绿作为「青瓷」意象，避免大面积高饱和红。
- 代码块转为深墨底，像在宣纸上落下一方浓墨。
