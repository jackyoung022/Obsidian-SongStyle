Songyun Qinghe 1.2.1 prepares 宋韵·清和 for the official Obsidian Community directory.

- Adds a root-level manifest and complete theme stylesheet for community installation.
- Bundles the matching line icons and dual-scroll folder states in the theme, with an optional Style Settings switch to restore native icons.
- Adds the MIT License, a 512×288 store thumbnail and desktop preview images.
- Keeps the existing light/dark palettes, paper grain, scroll callouts and reading layout.

Install through the community directory once the listing is published, or download the manual-install ZIP below. Fonts are optional and must be installed separately. No network assets are loaded by the theme.

Manual ZIP: copy `Songyun-Qinghe/` into your vault's `.obsidian/themes/` directory and select the theme in Appearance. Icons are now included, so a separate CSS snippet is no longer required.
