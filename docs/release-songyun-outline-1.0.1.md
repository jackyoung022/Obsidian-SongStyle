Songyun Outline 1.0.1 fixes a layout shift reported when a note first receives headings.

- The plugin no longer changes the article's left inset or horizontal margins.
- Text remains in the same centered position whether the note has no headings, has headings with the outline visible, or has the outline hidden.
- Paper tabs still overlay the left page gutter and keep the same hover, current-section and scroll-following behavior.

## Install

Download `Songyun-Outline-v1.0.1.zip`, replace the existing `songyun-outline/` plugin folder, then reload community plugins.
