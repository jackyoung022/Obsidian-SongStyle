Songyun Qinghe 1.3.0 deepens the Song-dynasty book and stationery aesthetic while keeping daily work notes clean and scannable.

### Highlights

- **Song woodblock & stationery typography**: Subtle stationery margin guides on wide screens, double-line `inline-title` and `h1` with a rouge seal stroke, double-ruled `h2`, diamond-marked `h3`, SVG fish-tail `hr` dividers, classic double-ruled tables, and woodblock-style Properties header blocks.
- **Traditional annotation & framing**: Subtle paper-mounted image frames with serif captions, brush-tint highlights with a fine rouge underline, bookmark-tab tags, hierarchical list markers, seal-style task checkboxes, and an optional Chinese emphasis-dot mode (`text-emphasis`) in place of italics.
- **Quiet interface refinements**: Ink-rubbing double-bordered code blocks, a minimal mountain-and-seal SVG emblem for empty tabs, and refined book-fold active tabs.
- **Expanded Song palettes & grain controls (Style Settings)**:
  - Light palettes: **Qinghe (default)**, **Tianqing (Ru celadon)**, **Songyan (bamboo & pine soot)**.
  - Dark palettes: **Dengxia (default)**, **Qiye Moyu (inkstone & jade)**.
  - Paper grain intensity (`default` / `soft` / `none`), first-line paragraph indent, and CJK top-level ordered list numerals.
- **Global & per-note stationery layouts**: Switch globally via Style Settings (**Default layout**) or per note via `cssclasses` (`song-letter`, `song-book`, `song-vertical`, `song-plain`).

Update **Songyun Qinghe** through Obsidian's theme manager, or use the manual-install ZIP below.
