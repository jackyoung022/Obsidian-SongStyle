Songyun Outline 1.0.0 is the first standalone companion plugin for Songyun Qinghe.

- Reads headings directly from the active note and builds a paper-tab outline without Floating TOC.
- Supports reading view, live preview and source mode.
- Keeps all headings collapsed by default, slightly highlights the current section and expands only the hovered paper tab.
- Tracks reading and editing position, closes headings into tight chapter groups, and navigates to headings on click.
- Provides independent settings for reading view, editing view and mobile.
- Listens to the Songyun theme's “隐藏页边纸签目录” switch, so the existing Style Settings control can hide the outline.

## Install

1. Download `Songyun-Outline-v1.0.0.zip`.
2. Copy the included `songyun-outline/` folder into `<your vault>/.obsidian/plugins/`.
3. Reload community plugins and enable **Songyun Outline**.

The plugin is distributed separately from the Songyun Qinghe theme and requires no third-party TOC plugin.
