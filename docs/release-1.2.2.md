This update fixes two issues reported by users of Songyun Qinghe.

- Font choices in Obsidian's Appearance settings now take precedence over the theme's defaults. The interface, editor, reading view and code blocks follow their respective font settings. Headings, quotes and callout titles follow the selected text font.
- The main Settings gear uses Obsidian's native icon, size and hit area again.

Update **Songyun Qinghe** through Obsidian's theme manager, or use the manual-install ZIP below. If you previously enabled a separate Songyun icon snippet, disable the old copy or replace it with the updated snippet.
