Songyun Qinghe 1.2.4 adds an optional paper-tab outline for users of the Floating TOC plugin.

- The heading rail uses compact paper tabs with left-aligned hierarchy and tighter groups for nested headings.
- Headings stay hidden until the pointer enters a tab; the current section is indicated by a subtle rouge accent only.
- Hovering expands the selected tab in place. The article gutter is responsive and returns to centered layout when the outline is hidden.
- A new Style Settings toggle, “隐藏页边纸签目录”, hides the Floating TOC rail and removes its left offset.

The outline styling requires the Floating TOC community plugin with its position set to the left. The core theme still works without additional plugins.

Update **Songyun Qinghe** through Obsidian's theme manager, or use the manual-install ZIP below.
